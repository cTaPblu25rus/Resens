# Формат уровней (`levels/levels.json`)

Файл содержит массив уровней («Тишей»), которые идут по порядку.
Все координаты нормализованы (0..1) относительно экрана: `[x, y]`, где y=0 — верх.
Ноты задаются номерами MIDI: 60 = До4, 64 = Ми4, 67 = Соль4, 72 = До5.

```jsonc
{
  "name": "Глушитель",              // название
  "hint": "Подсказка игроку",       // показывается в начале и гаснет после первых щипков
  "zone": [0.78, 1.0],              // необязательно: полоса по Y, где можно натягивать струны
  "scale": [0, 4],                  // необязательно: доступные ступени (0=До ... 11=Си), по умолчанию До мажор
  "heart": {"p": [0.5, 0.12], "chord": [0, 4, 7]},   // Сердце и его аккорд (ступени)
  "crystals": [{"p": [0.25, 0.88], "m": 60}],        // кристаллы: позиция и нота
  "mufflers": [                                       // необязательно: Глушители
    {"p": [0.5, 0.32], "r": 0.2,    // r — доля ширины экрана
     "notes": [62, 65, 69],         // ноты, по которым он плавает
     "period": 3.5,                 // секунд на одну ноту
     "hp": 2}                       // сколько попаданий нужно
  ],
  "par": 5,                         // щипков для оценки «★ идеально»
  "solution": [                     // эталонное решение для автотеста (обязательно!)
    {"t": 0.5, "target": 0, "p": [0.5, 0.9]},  // удар по Глушителю №0 (нота подбирается сама)
    {"t": 5.6, "m": 60, "p": [0.3, 0.92]}      // щипок ноты 60 с центром струны в p
  ]
}
```

## Правила механики (для дизайна)

| Порог | Значение | Смысл |
|---|---|---|
| Резонанс кристалла | 0.075 | пик волны × совпадение |
| Слух Сердца | 0.10 | только волны кристаллов |
| Удар по Глушителю | 0.06 | только унисон/октава с текущей нотой **в момент прихода** волны |
| Окно аккорда | 3.5 с | все ноты аккорда должны дойти до Сердца в этом окне |
| Перезарядка кристалла | 2 с | |

- Совпадение: унисон/октава = 1.0, квинта/кварта = 0.45, остальное = 0.
- Пик волны на расстоянии r: `exp(-0.7·r/420) / sqrt(1 + r/120) × сила`.
  Примерно: 200 px → 0.44, 400 → 0.25, 600 → 0.15, 800 → 0.095 (× сила).
- Сила щипка 0.55–1.0 (растёт с удержанием). Голос кристалла = 0.85 × сила входящей волны.
- Внутри живого Глушителя кристаллы и Сердце глухи.

## Проверка

```bash
godot --headless --path . -- --autoplay            # все уровни
godot --headless --path . -- --autoplay --level=3  # только уровень №4 (счёт с нуля)
```
CI запускает автотест на каждый push: уровень без рабочего `solution` не пройдёт сборку.
