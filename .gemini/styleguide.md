# Стайлгайд ревью RESONA (для Gemini Code Assist)

Полные правила ревью — в файле `GEMINI.md` в корне репозитория. Кратко:

- Проект: Android-игра на Godot 4.3 (GDScript + шейдеры canvas_item, рендерер GL Compatibility).
- Ревью пиши на русском языке.
- Приоритеты: корректность → производительность на мобильных → согласованность
  физики волн между `scripts/main.gd` (`_envelope`) и `shaders/waves.gdshader` (`wave_at`)
  → соответствие `docs/GDD.md`.
- Помечай важность: 🔴 ошибка, 🟡 стоит исправить, 🟢 идея.
- GDScript: статическая типизация обязательна, скрипты подключаются через `preload`.
