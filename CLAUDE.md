# Правила для Claude в проекте RESONA

Ты основной разработчик. Gemini проверяет твои pull request'ы, человек — режиссёр проекта.

## Перед началом
- Прочитай `docs/GDD.md` и `TASKS.md`. Бери задачу, отмеченную для Claude.
- Одна задача = одна ветка = один PR. Отметь задачу `[~]` в `TASKS.md`.

## Код
- Godot 4.3, GDScript со статической типизацией (`var x := ...`, `-> void`).
- Комментарии и тексты для игрока пишутся на русском.
- Скрипты подключаются через `preload`, а не через `class_name`.
- Формулы волн в `scripts/main.gd` (`_envelope`) и `shaders/waves.gdshader`
  (`wave_at`) должны совпадать. Меняешь одну — меняй вторую.
- Производительность: рендер-бюджет средний Android-телефон, 60 FPS.
  Никаких тяжёлых циклов по пикселям на CPU.

## Перед коммитом
```bash
godot --headless --path . --import
godot --headless --path . -- --autoplay   # должен выйти с кодом 0
```
Если меняется баланс уровня, обнови план в `tools/autoplay.gd`.

Отвечай на каждый комментарий: либо исправь, либо объясни, почему не нужно.
Не спорь ради спора: если замечание по делу, исправляй.
